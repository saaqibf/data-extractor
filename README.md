# MindFuel Data Extractor

A free team tool built for the MindFuel Foundation: paste a web page URL, drop in a PDF, or paste any table or text, and get a clean table you can download as CSV or copy to your clipboard.

**Use it here: https://saaqibf.github.io/data-extractor**

Everything runs in your browser. Nothing you paste or upload leaves your computer. No accounts, no installs, no cost. Built-in instructions and a working example button, so it explains itself.

Known limit: some websites block direct URL reading (a browser security rule called CORS). When that happens, copy the page content and use the "Paste anything" tab, which always works.

Built by Saaqib Fagbenro, MindFuel Foundation internship, summer 2026.
